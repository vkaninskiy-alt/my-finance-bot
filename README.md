# Семейный бюджет — Telegram-бот

## Возможности
- Личные и семейные расходы. Участники семейной группы выбирают бюджет при добавлении; личные расходы видны только автору, семейные — участникам группы.
- Быстрый ввод в формате `12,50 продукты хлеб`, `3.50 кофе`, `20 такси`.
- В разделе «➕ Добавить расход» есть отдельная кнопка «🧾 Распознать чек». OCR пытается извлечь итоговую сумму, магазин и дату; перед записью бот показывает данные на проверку, позволяет исправить сумму и повторно не добавляет уже сохранённый Telegram-чек.
- История, редактирование суммы, удаление, статистика и месячный лимит.

## Запуск
1. Установи Node.js 18+.
2. Скопируй `.env.example` в `.env` и укажи токен Telegram-бота.
3. Выполни `npm install`.
4. Запусти `npm run check`, `npm test`, затем `npm start`.

Для распознавания чеков `tesseract.js` загружает языковые данные при первом запуске; потребуется интернет. Установи зависимости командой `npm install` и проверь, что `tesseract.js` есть в `dependencies`. OCR может ошибаться: сумма, магазин и дата показываются на проверку до сохранения. Дубликаты фото чеков проверяются по `file_unique_id` Telegram.

Перед обновлением сделай копию `expenses.db`. При первом запуске новая колонка `budget_type` добавляется автоматически; старые расходы участников существующих семейных групп помечаются как семейные, остальные — как личные.

`APP_TIMEZONE` необязателен, например `Europe/Tallinn`.
